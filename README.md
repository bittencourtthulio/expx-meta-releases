# EXPX Meta — instaladores

App desktop de gestão agêntica de campanhas Meta da EXPX.

Este repositório guarda **só os instaladores** publicados em [Releases](../../releases). O app instalado consulta
estas releases para se atualizar sozinho. O código-fonte não fica aqui.

| Sistema | Arquivo |
|---|---|
| macOS (Apple Silicon e Intel) | `EXPX-Meta-<versão>-mac-universal.dmg` |
| Windows 64 bits | `EXPX-Meta-<versão>-win-x64.exe` |
| Windows ARM | `EXPX-Meta-<versão>-win-arm64.exe` |
